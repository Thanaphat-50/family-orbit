## STEP 1 — สร้างอีเมลติดต่อ แล้วใส่ใน Laravel Cloud

- [ ] สร้างอีเมลใหม่สำหรับแอป เช่น Gmail ชื่อเดียวกับแอป

## STEP 2 — สมัครบัญชีนักพัฒนา Google Play

- [ ] เข้า https://play.google.com/console/signup ด้วยบัญชี Google ที่จะใช้ดูแลแอประยะยาว
- [ ] เลือกบัญชีแบบ **บุคคล (Personal)**
- [ ] จ่ายค่าสมัครครั้งเดียว 25 ดอลลาร์สหรัฐ
- [ ] ยืนยันตัวตนด้วยบัตรประชาชน ยืนยันเบอร์โทรและอีเมลตามที่ Google ขอ
- [ ] ถ้า Google ขอให้ยืนยันว่ามีมือถือ Android ให้ติดตั้งแอป Play Console บนมือถือแล้วทำตาม

> บัญชีบุคคลที่สมัครใหม่ต้อง **ทดสอบแบบปิดกับผู้ทดสอบอย่างน้อย 12 คน ติดต่อกัน 14 วัน** ก่อนขอเปิดให้ทุกคนโหลด (STEP 6)

## STEP 4 — กรอก "App content" (เนื้อหาแอป)

| หัวข้อ | สิ่งที่กรอก |
|---|---|
| Privacy policy | ลิงก์นโยบายความเป็นส่วนตัว |
| App access | เลือก "ต้องเข้าสู่ระบบ" แล้วใส่บัญชีทดสอบสำหรับผู้ตรวจของ Google (ดูหมายเหตุด้านล่าง) |
| Ads | ไม่มีโฆษณา |
| Content rating | ตอบแบบสอบถาม: เป็นแอปสื่อสาร/โซเชียล, ผู้ใช้โพสต์และโต้ตอบกันได้, แชร์ตำแหน่งกับผู้ใช้อื่น (ครอบครัว), ไม่มีการซื้อสินค้าดิจิทัลในแอป |
| Target audience | แนะนำ **18 ปีขึ้นไป** ช่วงแรก (ถ้าเลือกต่ำกว่า 13 ปี จะเข้าข้อบังคับ Families ที่เข้มมาก) |
| News app / Government / Financial / Health | ไม่ใช่ |
| Data safety | ดูตารางคำตอบด้านล่าง |
| Account deletion | ลิงก์หน้าลบบัญชี |
| Child safety standards | ลิงก์มาตรฐานความปลอดภัยของเด็ก + อีเมลติดต่อจาก STEP 1 |

**ตำแหน่งเบื้องหลัง (Location permissions declaration):**
แอปขอ `ACCESS_BACKGROUND_LOCATION` สำหรับ "แชร์แม้ไม่ได้เปิดแอป" → Play Console จะให้กรอกแบบฟอร์มนี้
- จุดประสงค์: แชร์ตำแหน่งปัจจุบันกับสมาชิกครอบครัวที่ผู้ใช้เลือกเข้าร่วม (ฟีเจอร์หลักของแอป) ผู้ใช้เปิดเองที่ ตั้งค่า
- ต้องแนบ **วิดีโอสั้น** ที่แสดง: หน้าต่างอธิบาย "แชร์ตำแหน่งแม้ไม่ได้เปิดแอป" → กดดำเนินการต่อ → เลือก "อนุญาตตลอดเวลา" → แจ้งเตือน "ใกล้กันกำลังแชร์ตำแหน่ง" → อีกเครื่องเห็นตำแหน่งขยับขณะปิดแอป
- Data safety: ตำแหน่งที่แน่นอน (Precise location) — เก็บ, แชร์กับผู้ใช้อื่น (ครอบครัว), ใช้เพื่อฟีเจอร์ของแอป, ผู้ใช้เลือกได้ (ปิดได้)

**หมายเหตุบัญชีผู้ตรวจ (App access):**
- สมัครบัญชีใหม่ในแอปจริง (เช่น อีเมลที่สร้างแยกไว้ให้ผู้ตรวจ) สร้างครอบครัว และโพสต์ตัวอย่างไว้ 1–2 โพสต์
- ใส่อีเมลและรหัสผ่านนี้ **ในฟอร์มของ Play Console เท่านั้น** ห้ามเก็บไว้ในโค้ดหรือส่งในแชต

### คำตอบแบบฟอร์ม Data safety (ร่าง — ตรวจกับคำอธิบายของ Google อีกครั้งก่อนส่ง)

คำถามภาพรวม:
- เก็บหรือแชร์ข้อมูลผู้ใช้ไหม → **ใช่**
- เข้ารหัสข้อมูลระหว่างส่งไหม → **ใช่** (HTTPS)
- ผู้ใช้ขอลบข้อมูลได้ไหม → **ได้** (ในแอป และลิงก์หน้าลบบัญชี)

ข้อมูลแต่ละประเภท (ทุกข้อ: **เก็บ = ใช่, แชร์ให้บุคคลที่สาม = ไม่**, จุดประสงค์ = การทำงานของแอป):

| หมวดของ Google | ข้อมูลในแอปเรา | บังคับ / ไม่บังคับ | จุดประสงค์เพิ่ม |
|---|---|---|---|
| Location → Precise location | ตำแหน่งล่าสุด (แสดงเฉพาะครอบครัว) | ไม่บังคับ | — |
| Personal info → Name | ชื่อที่แสดง | บังคับ | Account management |
| Personal info → Email address | อีเมลเข้าสู่ระบบ | บังคับ | Account management |
| Personal info → User IDs | หมายเลขบัญชีผู้ใช้ | บังคับ | Account management |
| Personal info → Phone number | เบอร์โทรร้านค้า (เฉพาะผู้ขาย) | ไม่บังคับ | — |
| Personal info → Other info | LINE ID และพื้นที่ขายของร้าน | ไม่บังคับ | — |
| Photos and videos → Photos | รูปโปรไฟล์ รูปโพสต์ รูปสินค้า | ไม่บังคับ | — |
| Messages → Other in-app messages | โพสต์ ความคิดเห็น และแชทส่วนตัวในครอบครัว | ไม่บังคับ | — |
| App activity → Other user-generated content | กิจกรรม ร้านค้า สินค้า การถูกใจ รายงาน | ไม่บังคับ | Fraud prevention, security (สำหรับรายงาน) |
| App activity → In-app search history | คำค้นในตลาด (ใช้ค้นแล้วไม่เก็บ = processed ephemerally) | ไม่บังคับ | — |
| App info and performance → Crash logs | รายงานเมื่อแอปเด้ง (Firebase Crashlytics) | บังคับ | Analytics |
| App info and performance → Diagnostics | รุ่นเครื่อง เวอร์ชันระบบ/แอป ที่ส่งมากับรายงาน | บังคับ | Analytics |
| Device or other IDs | รหัสเครื่องสำหรับแจ้งเตือน (Firebase Installation ID) | บังคับ | — |

> เหตุผลที่ตอบ "ไม่แชร์": ข้อมูลที่แสดงให้ผู้ใช้อื่นในแอปเห็นตามที่ผู้ใช้เลือกเอง (เช่น แชร์ตำแหน่งกับครอบครัว หรือโพสต์ในชุมชน)
> Google ไม่นับเป็นการแชร์ให้บุคคลที่สาม และเราไม่ได้ส่งข้อมูลให้บริษัทอื่น
> (Firebase ประมวลผลแทนเราในฐานะผู้ให้บริการ จึงไม่นับเป็นการแชร์เช่นกัน)

## STEP 7 — ล็อก Google Maps API Key

ทำหลัง STEP 6 เพราะต้องใช้ SHA-1 ที่ Google สร้างให้ตอนเปิด App Signing

1. Play Console → Test and release → Setup → App signing (App integrity) → คัดลอก **SHA-1 ของ App signing key**
2. Google Cloud Console → APIs & Services → Credentials → เลือก API key ของแอป
3. Application restrictions → **Android apps** → เพิ่ม 3 รายการ (package `com.familyorbit.app` ทุกรายการ):

| ใช้กับ | SHA-1 |
|---|---|
| แอปที่โหลดจาก Play Store | (SHA-1 ของ App signing key จากข้อ 1) |
| APK ที่ Build เองแบบ Release | `F7:FB:65:58:D0:8E:6C:87:B2:EE:5D:F5:A6:4D:F8:3F:2A:CB:6B:26` |
| ทดสอบบน Emulator (Debug) | `6F:CA:30:04:08:A1:D2:67:3C:CB:F7:F5:EB:F7:91:75:C9:48:6B:CD` |

4. API restrictions → Restrict key → เลือกเฉพาะ **Maps SDK for Android** → Save
5. เปิดแอปแล้วตรวจว่าแผนที่ยังขึ้นปกติ (การตั้งค่าอาจใช้เวลาสักครู่กว่าจะมีผล)
