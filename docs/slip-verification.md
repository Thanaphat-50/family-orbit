# ตรวจสลิปโอนเงินอัตโนมัติ (EasySlip)

ลูกค้าแนบสลิป → ระบบส่งรูปไปตรวจกับ EasySlip → เทียบกับคำสั่งซื้อ

| ผลตรวจ | เกิดอะไรขึ้น |
|---|---|
| ผ่าน (โอนจริง ยอดครบ เข้าบัญชีร้าน ไม่ใช่สลิปซ้ำ) | **ชำระแล้ว → รอร้านจัดส่ง** ทันที |
| ไม่ผ่าน (สลิปปลอม ยอดไม่ครบ บัญชีอื่น สลิปซ้ำ โอนก่อนสั่ง) | ลูกค้าเห็นเหตุผล แนบสลิปใหม่ได้ (ไม่เก็บรูปสลิปที่ไม่ผ่าน) |
| ตรวจอัตโนมัติไม่ได้ (ยังไม่ตั้งคีย์ / ระบบล่ม / โอนเกิน / อ่านบัญชีผู้รับไม่ได้) | **รอตรวจสอบการชำระเงิน** → ร้านเช็กยอดในแอปธนาคาร แล้วกด "ยืนยันว่าได้รับเงินแล้ว" |

ระบบไม่เปลี่ยนเป็น "ชำระแล้ว" จากการแนบสลิปเฉย ๆ

## STEP 1: สมัคร EasySlip

1. เข้า https://easyslip.com → สมัครบัญชี
2. ยืนยันตัวตน (KYC) ให้เสร็จ (ต้องทำก่อนใช้งานจริง)
3. เลือกแพ็กเกจตามจำนวนสลิปต่อเดือน
4. สร้าง **API Key** (API v2 แบบ Bearer token)
5. **ไม่ต้องเปิด IP whitelist** (Laravel Cloud ไม่มี IP ตายตัว ถ้าเปิดจะตรวจไม่ได้)

## STEP 2: ใส่คีย์ใน Laravel Cloud

Laravel Cloud → Environment → Variables:

| ตัวแปร | ใส่อะไร |
|---|---|
| `EASYSLIP_API_KEY` | API Key จาก EasySlip (ห้ามส่งให้ใคร ห้ามใส่ในแอป) |

ยังไม่ใส่ → ทุกสลิปไปที่ "รอตรวจสอบการชำระเงิน" ให้ร้านกดยืนยันเอง

## STEP 3: ทดสอบ

1. สั่งซื้อแบบโอนพร้อมเพย์ด้วยบัญชีทดสอบ โอนจริงยอดเล็ก ๆ
2. แนบสลิป → ต้องขึ้น "ชำระเงินสำเร็จ ระบบตรวจสลิปแล้ว"
3. แนบสลิปเดิมกับคำสั่งซื้ออื่น → ต้องขึ้น "สลิปนี้ถูกใช้ชำระไปแล้ว"

## ข้อควรรู้

- ระบบเทียบบัญชีผู้รับจากเลขที่สลิปแสดง (สลิปปิดบางหลัก) กับพร้อมเพย์/เลขบัญชีของร้าน
  ร้านต้องใส่เลขพร้อมเพย์/บัญชีให้ถูกในหน้า "แก้ไขข้อมูลร้าน"
- โอนเข้าพร้อมเพย์แล้วสลิปไม่แสดงเบอร์/เลขบัตร → ไปที่ร้านตรวจเอง
- ธนาคารกรุงเทพอาจยังตรวจไม่ได้ใน 5 นาทีแรก → ไปที่ร้านตรวจเอง
- ประวัติการตรวจทุกครั้งอยู่ในคำสั่งซื้อ (ประวัติการชำระเงิน)
