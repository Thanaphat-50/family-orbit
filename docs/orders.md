# ระบบสั่งซื้อสินค้า

เงินโอนเข้าร้านโดยตรง แอปไม่ได้รับเงินแทน (ไม่ต้องสมัครระบบรับชำระเงิน)
**ไม่ต้องรอร้านยืนยันคำสั่งซื้อ**

## ขั้นตอน

1. ผู้ซื้อกด **ซื้อเลย** (หรือใส่ตะกร้าแล้วสั่งหลายชิ้น) → เลือกตัวเลือกสินค้า จำนวน ที่อยู่ วิธีรับสินค้า และวิธีชำระเงิน
   - สินค้าจากหลายร้าน = แยกเป็น 1 คำสั่งซื้อต่อ 1 ร้าน
   - ราคา/ค่าส่งคิดที่เซิร์ฟเวอร์ ราคาเปลี่ยนระหว่างนี้ → ให้ตรวจยอดใหม่ก่อนสั่ง
2. ระบบ **จองสต็อก** ทันที → ร้านได้แจ้งเตือน "มีคำสั่งซื้อใหม่"
3. ชำระเงิน
   - **โอนพร้อมเพย์ / บัญชีธนาคาร**: ผู้ซื้อเห็น QR หรือเลขบัญชีของร้านทันที → โอน → แนบสลิป
     → **ระบบตรวจสลิปอัตโนมัติ** (ดู [slip-verification.md](slip-verification.md))
     ผ่าน = **รอร้านจัดส่ง** / ตรวจไม่ได้ = **รอตรวจสอบการชำระเงิน** (ร้านเช็กยอดแล้วกดยืนยัน)
   - **เก็บเงินปลายทาง / เงินสดตอนรับของ**: เป็น **รอร้านจัดส่ง** ตั้งแต่กดสั่ง
4. ร้านกด **ส่งสินค้าแล้ว** หรือ **ส่งมอบสินค้าแล้ว** (รับที่ร้าน / นัดรับ)
   - ส่งพัสดุ: **ต้องเลือกบริษัทขนส่ง** (ไปรษณีย์ไทย, Flash, KEX, J&T, SPX, Ninja Van ...)
     ขนส่งที่มีเลขพัสดุต้องกรอก **เลขพัสดุ** (ลูกค้าเห็นและคัดลอกได้)
   - ส่งถึงบ้าน: เลือก Lalamove / Grab / LINE MAN / ร้านไปส่งเอง ได้ (ไม่บังคับ)
   - รายชื่อขนส่งอยู่ที่ `config/market.php` → `carriers`
5. ผู้ซื้อกด **ได้รับสินค้าแล้ว** → สำเร็จ → **ให้คะแนนสินค้า** (1–5 ดาว + ความเห็น) และรีวิวร้านได้

ทุกการเปลี่ยนสถานะและทุกการแนบสลิปเก็บเป็นประวัติในคำสั่งซื้อ
ในหน้าคำสั่งซื้อ ผู้ซื้อกด **แชทกับร้าน** / ร้านกด **แชทกับลูกค้า** ได้

ยกเลิก (คืนสต็อกให้เอง):
- ผู้ซื้อ: ก่อนโอน หรือ เก็บเงินปลายทาง/เงินสดที่ร้านยังไม่ส่ง
  โอนแล้วยกเลิกได้เมื่อร้านไม่ส่งภายในกำหนด
- ร้าน: ก่อนส่งสินค้า ต้องบอกเหตุผล

## คืนเงิน

ยกเลิกหลังลูกค้าโอนแล้ว (ชำระแล้ว หรือส่งสลิปรอร้านตรวจ) → **ยกเลิกแล้ว · รอร้านคืนเงิน**

1. ร้านโอนเงินคืนลูกค้าเอง (บัญชีที่ลูกค้าโอนมา ดูได้จากสลิป หรือแชทถามลูกค้า)
2. ร้านกด **คืนเงินให้ลูกค้าแล้ว** + บอกช่องทาง/เลขอ้างอิง → ลูกค้าได้แจ้งเตือน → **คืนเงินแล้ว**

ระหว่างรอคืนเงิน คำสั่งซื้อนี้อยู่ในแท็บ **ต้องจัดการ** ของร้าน
ผู้ดูแลกรอง **การคืนเงิน: รอร้านคืนเงิน** ใน `/admin` → คำสั่งซื้อ เพื่อติดตามร้านที่ยังไม่คืน

## ยอดขายของร้าน

ร้านของฉัน → **ยอดขาย** (หรือปุ่มยอดขายในหน้าออเดอร์ของร้าน)

- ยอดขาย = คำสั่งซื้อที่ **สำเร็จ** (ลูกค้าได้รับสินค้าแล้ว) นับตามวันที่สำเร็จ เวลาไทย
- วันนี้ / เดือนนี้ / ทั้งหมด, กราฟ 7 วันล่าสุด, สินค้าขายดีเดือนนี้
- กำลังดำเนินการ (รอจัดส่ง / กำลังส่ง) แยกไว้ ยังไม่นับเป็นยอดขาย
- **ดูประวัติการขาย** = แท็บ "สำเร็จ" ในออเดอร์ของร้าน

## ร้านต้องตั้งค่าอะไร

ร้านของฉัน → แก้ไขข้อมูลร้าน:

- **วิธีรับสินค้า** อย่างน้อย 1 แบบ
- **วิธีรับเงิน** อย่างน้อย 1 แบบ (พร้อมเพย์ต้องใส่เบอร์/เลข 13 หลัก, ธนาคารต้องใส่ธนาคาร + เลขบัญชี)

ยังไม่ตั้ง → ในหน้าสินค้าขึ้นว่า "ร้านนี้ยังไม่เปิดรับคำสั่งซื้อในแอป"

เงินสดใช้ได้กับรับที่ร้าน/นัดรับ, เก็บเงินปลายทางใช้ได้กับส่งพัสดุ/ส่งถึงบ้าน

ลงสินค้า: ใส่ **จำนวนในสต็อก** (ขายได้ระบบลดเอง ถึง 0 = สินค้าหมด) และ **ค่าส่ง** (คิดครั้งเดียวต่อคำสั่งซื้อ)

## เวลาอัตโนมัติ (ไม่บังคับ ตั้งใน Laravel Cloud ได้)

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `ORDER_PAYMENT_HOURS` | 24 | เลือกโอนแต่ไม่แนบสลิปภายในกี่ชั่วโมง → ยกเลิกเอง |
| `ORDER_SHIP_DAYS` | 3 | ร้านควรส่งภายในกี่วัน (เกินแล้วผู้ซื้อยกเลิกได้แม้โอนแล้ว) |
| `ORDER_AUTO_COMPLETE_DAYS` | 7 | ส่งแล้วผู้ซื้อไม่กดได้รับภายในกี่วัน → สำเร็จเอง |

## ผู้ดูแล

`/admin` → เมนู **คำสั่งซื้อ** ดูได้ทุกรายการ (สถานะ ยอดเงิน สลิป) ใช้ตรวจเมื่อมีปัญหาระหว่างผู้ซื้อกับร้าน

## การ์ดวิดีโอ

ฟอร์มสินค้า → **หน้าปกการ์ดสินค้า** เลือก "วิดีโอ" (ต้องมีวิดีโอสินค้าก่อน)
การ์ดเล่นวิดีโอเอง (ไม่มีเสียง) เมื่อเลื่อนมาหยุด หรือแตะ/วางเมาส์ที่การ์ด เล่นทีละการ์ด
