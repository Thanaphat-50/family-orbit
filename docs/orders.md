# ระบบสั่งซื้อสินค้า

เงินโอนเข้าร้านโดยตรง แอปไม่ได้รับเงินแทน (ไม่ต้องสมัครระบบรับชำระเงิน)
**ไม่ต้องรอร้านยืนยันคำสั่งซื้อ**

## ขั้นตอน

1. ผู้ซื้อกด **สั่งซื้อ** ในหน้าสินค้า → เลือกจำนวน วิธีรับสินค้า ที่อยู่ และวิธีชำระเงิน
2. ระบบ **จองสต็อก** ทันที → ร้านได้แจ้งเตือน "มีคำสั่งซื้อใหม่"
3. ชำระเงิน
   - **โอนพร้อมเพย์ / บัญชีธนาคาร**: ผู้ซื้อเห็น QR หรือเลขบัญชีของร้านทันที → โอน → แนบสลิป
     → สถานะเป็น **รอร้านจัดส่ง** ทันที (ร้านได้แจ้งเตือน "ลูกค้าโอนเงินแล้ว")
   - **เก็บเงินปลายทาง / เงินสดตอนรับของ**: เป็น **รอร้านจัดส่ง** ตั้งแต่กดสั่ง
4. ร้านเช็กยอดเงินในแอปธนาคาร แล้วกด **ส่งสินค้าแล้ว** (ใส่เลขพัสดุได้) หรือ **ส่งมอบสินค้าแล้ว** (รับที่ร้าน / นัดรับ)
   - เงินไม่เข้า → กด **สลิปไม่ถูกต้อง** ผู้ซื้อต้องแนบสลิปใหม่
5. ผู้ซื้อกด **ได้รับสินค้าแล้ว** → สำเร็จ (ชวนรีวิวร้าน)

ยกเลิก (คืนสต็อกให้เอง):
- ผู้ซื้อ: ก่อนโอน หรือ เก็บเงินปลายทาง/เงินสดที่ร้านยังไม่ส่ง
  โอนแล้วยกเลิกได้เมื่อร้านไม่ส่งภายในกำหนด (ร้านต้องคืนเงิน)
- ร้าน: ก่อนส่งสินค้า ต้องบอกเหตุผล (ถ้าลูกค้าโอนแล้วต้องคืนเงิน)

## ร้านต้องตั้งค่าอะไร

ร้านของฉัน → แก้ไขข้อมูลร้าน:

- **วิธีรับสินค้า** อย่างน้อย 1 แบบ
- **วิธีรับเงิน** อย่างน้อย 1 แบบ (พร้อมเพย์ต้องใส่เบอร์/เลข 13 หลัก, ธนาคารต้องใส่ธนาคาร + เลขบัญชี)

ยังไม่ตั้ง → ในหน้าสินค้าขึ้นว่า "ร้านนี้ยังไม่เปิดรับคำสั่งซื้อในแอป"

เงินสดใช้ได้กับรับที่ร้าน/นัดรับ, เก็บเงินปลายทางใช้ได้กับส่งพัสดุ/ส่งถึงบ้าน

ลงสินค้า: ใส่ **จำนวนในสต็อก** (ขายได้ระบบลดเอง ถึง 0 = สินค้าหมด) และ **ค่าส่ง** (คิดครั้งเดียวต่อคำสั่งซื้อ)

## เวลาอัตโนมัติ (ไม่บังคับ ตั้งใน Laravel Cloud ได้)

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `ORDER_PAYMENT_HOURS` | 24 | เลือกโอนแต่ไม่แนบสลิปภายในกี่ชั่วโมง → ยกเลิกเอง |
| `ORDER_SHIP_DAYS` | 3 | ร้านควรส่งภายในกี่วัน (เกินแล้วผู้ซื้อยกเลิกได้แม้โอนแล้ว) |
| `ORDER_AUTO_COMPLETE_DAYS` | 7 | ส่งแล้วผู้ซื้อไม่กดได้รับภายในกี่วัน → สำเร็จเอง |

## ผู้ดูแล

`/admin` → เมนู **คำสั่งซื้อ** ดูได้ทุกรายการ (สถานะ ยอดเงิน สลิป) ใช้ตรวจเมื่อมีปัญหาระหว่างผู้ซื้อกับร้าน

## การ์ดวิดีโอ

ฟอร์มสินค้า → **หน้าปกการ์ดสินค้า** เลือก "วิดีโอ" (ต้องมีวิดีโอสินค้าก่อน)
การ์ดเล่นวิดีโอเอง (ไม่มีเสียง) เมื่อเลื่อนมาหยุด หรือแตะ/วางเมาส์ที่การ์ด เล่นทีละการ์ด
