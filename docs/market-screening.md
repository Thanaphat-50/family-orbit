# ตรวจสินค้าต้องห้าม + รายงานร้านค้า

ผู้ขายเปิดร้านและลงสินค้าได้เลย ไม่ต้องรอผู้ดูแลอนุมัติ
ความปลอดภัยใช้ 2 ระบบ: **ตรวจคำต้องห้ามอัตโนมัติ** และ **รายงานจากผู้ใช้**

## 1. ตรวจคำต้องห้ามอัตโนมัติ

ระบบตรวจ **ชื่อและรายละเอียด** ของร้านและสินค้าทุกครั้งที่ลงใหม่หรือแก้ไข
กับคำในรายการ `prohibited` ใน `family_api/config/market.php` (10 กลุ่ม):
เครื่องดื่มแอลกอฮอล์, บุหรี่/บุหรี่ไฟฟ้า, ยาเสพติด, ยา/อาหารเสริมผิดกฎหมาย, อาวุธ,
ของปลอม, สัตว์ป่า, การพนัน, สินค้าสำหรับผู้ใหญ่, บัญชีม้า/เอกสารปลอม

- ไม่สนช่องว่าง เครื่องหมาย ตัวพิมพ์ (เขียน "บ ุ-ห รี่" ก็ตรวจเจอ)
- วลีที่ไม่ผิดกฎอยู่ใน `allow_phrases` เช่น ปืนฉีดน้ำ ตลับลูกปืน เจลแอลกอฮอล์ สุราษฎร์ธานี

**เมื่อตรวจพบ:**

1. **ซ่อนทันที** — สินค้าถูกซ่อน / ร้านถูกปิดชั่วคราว และเจ้าของร้านได้รับแจ้งว่า "รอทีมงานตรวจสอบ"
2. ผู้ดูแลทุกคน (บัญชี Admin) ได้รับ **แจ้งเตือนในแอป + แจ้งเตือนเด้งบนมือถือ**
3. เข้า `/admin` → เมนู **ตรวจพบสินค้าต้องห้าม** (ตัวเลขสีแดง = รอตรวจ) แล้วเลือก:
   - **ผิดกฎจริง** — ซ่อนต่อ ปิดรายการ
   - **ระงับร้าน** — ปิดทั้งร้าน พร้อมเหตุผลให้เจ้าของร้าน
   - **ไม่ผิดกฎ** — แสดงสินค้า / เปิดร้านคืนให้ และแจ้งเจ้าของร้าน (คำเดิมจะไม่ถูกซ่อนซ้ำ)

## 2. รายงานร้านค้าจากผู้ใช้

- ปุ่ม **"รายงานร้านนี้"** อยู่ท้ายหน้าร้าน (และในเมนู ⋮) / รายงานสินค้าได้ที่เมนู ⋮ ในหน้าสินค้า
- ผู้ใช้เลือกเหตุผล แล้วเล่ารายละเอียดได้ (ไม่บังคับ) เจ้าของร้านไม่รู้ว่าใครรายงาน
- ทุกรายงานใหม่ → ผู้ดูแลทุกคนได้รับแจ้งเตือนพร้อมเหตุผลและรายละเอียด
- สินค้าถูกรายงานครบ 3 คน → ซ่อนอัตโนมัติ (`MARKET_AUTO_HIDE_REPORTS`)
- ร้านถูกรายงานครบ 5 คน → ปิดร้านชั่วคราวอัตโนมัติ (`MARKET_AUTO_SUSPEND_SHOP_REPORTS`)
- เข้า `/admin` → เมนู **รายงานร้านค้า** แล้วเลือก:
  - **ระงับร้าน** — พร้อมเหตุผล
  - **ไม่ผิดกฎ เปิดร้านคืน** — สำหรับร้านที่ระบบปิดเพราะถูกรายงาน (ล้างรายงานของร้านนั้นด้วย)
  - **ลบรายงาน** — รายงานที่ไม่มีมูล

## ข้อควรรู้

- ต้องเป็นบัญชี Admin ถึงจะได้รับแจ้งเตือน (ตั้งด้วยคำสั่ง `php artisan app:make-admin` ตามคู่มือ Admin)
- ระบบตรวจจากคำเท่านั้น ไม่ได้ดูรูป จึงยังต้องอาศัยรายงานจากผู้ใช้
- เพิ่ม/ลบคำต้องห้ามได้ที่ `config/market.php` แล้ว push ขึ้น GitHub
