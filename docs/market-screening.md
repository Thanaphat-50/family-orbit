# ตรวจสินค้าต้องห้ามอัตโนมัติ (ร้านเปิดขายได้ทันที)

ผู้ขายเปิดร้านและลงสินค้าได้เลย ไม่ต้องรอผู้ดูแลอนุมัติ
ระบบจะตรวจ **ชื่อและรายละเอียด** ของร้านและสินค้าทุกครั้งที่ลงใหม่หรือแก้ไข

## ระบบตรวจอะไร

คำในรายการ `prohibited` ใน `family_api/config/market.php` แบ่งเป็น 10 กลุ่ม:
เครื่องดื่มแอลกอฮอล์, บุหรี่/บุหรี่ไฟฟ้า, ยาเสพติด, ยา/อาหารเสริมผิดกฎหมาย, อาวุธ,
ของปลอม, สัตว์ป่า, การพนัน, สินค้าสำหรับผู้ใหญ่, บัญชีม้า/เอกสารปลอม

- ไม่สนช่องว่าง เครื่องหมาย ตัวพิมพ์ (เขียน "บ ุ-ห รี่" ก็ตรวจเจอ)
- วลีที่ไม่ผิดกฎอยู่ใน `allow_phrases` เช่น ปืนฉีดน้ำ ตลับลูกปืน เจลแอลกอฮอล์ สุราษฎร์ธานี
- เพิ่ม/ลบคำได้ที่ไฟล์นี้ แล้ว push ขึ้น GitHub

## เมื่อตรวจพบ

1. ผู้ดูแลทุกคน (บัญชีที่เป็น Admin) ได้รับ **แจ้งเตือนในแอป + แจ้งเตือนเด้งบนมือถือ**
   กดแจ้งเตือนแล้วเปิดหน้าสินค้า/ร้านนั้นได้เลย
2. สินค้า **ยังไม่ถูกซ่อนเอง** (กันซ่อนผิดจากคำที่บังเอิญตรง)
3. เข้า `/admin` → เมนู **ตรวจพบสินค้าต้องห้าม** (ตัวเลขสีแดง = รอตรวจ) แล้วเลือก:
   - **ซ่อนสินค้า** — ผู้ซื้อมองไม่เห็นสินค้านั้น
   - **ระงับร้าน** — ปิดทั้งร้าน พร้อมแจ้งเหตุผลให้เจ้าของร้าน
   - **ไม่ผิดกฎ** — ปิดรายการ คำเดิมจะไม่แจ้งซ้ำ (แจ้งใหม่เมื่อมีคำต้องห้ามคำใหม่)

## ข้อควรรู้

- ต้องเป็นบัญชี Admin ถึงจะได้รับแจ้งเตือน (ตั้งด้วยคำสั่ง `php artisan app:make-admin` ตามคู่มือ Admin)
- ระบบตรวจจากคำเท่านั้น ไม่ได้ดูรูป ยังควรเปิดดูรายงานจากผู้ใช้ด้วย (เมนูสินค้า/ร้านค้าในหลังบ้าน)
- ร้านที่เคยรออนุมัติอยู่ ถูกเปิดขายให้อัตโนมัติ และถูกตรวจย้อนหลังหนึ่งรอบตอนอัปเดตระบบ
